# 🌐 Módulo 1 — Las redes en la actualidad

En este módulo estudié los fundamentos de las redes, desde los dispositivos
que participan en una comunicación hasta los diferentes tipos de redes,
medios de conexión y características necesarias para construir una red
confiable.
