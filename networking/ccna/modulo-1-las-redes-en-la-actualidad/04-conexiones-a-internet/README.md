# 📡 Conexiones a Internet

## 🌐 Tecnologías de acceso a Internet

Los usuarios domésticos, trabajadores remotos y oficinas pequeñas necesitan conectarse a un **ISP (Internet Service Provider)** para acceder a Internet.

Algunas tecnologías de acceso son:

- Banda ancha por cable
- DSL
- WAN inalámbrica
- Redes móviles


---

## 🏠 Conexiones domésticas y de pequeñas oficinas

### 📊 Ancho de banda

El **ancho de banda** es la capacidad máxima de una conexión para transmitir datos por unidad de tiempo.

Se mide en **bits por segundo (bps)** y sus múltiplos, como Mbps o Gbps.

> Mayor ancho de banda = mayor capacidad para transmitir datos.

---

### 📞 Dial-up

La conexión **Dial-up** utiliza una línea telefónica y un módem para conectarse a Internet.

Tiene un **ancho de banda muy bajo**, por lo que no es adecuada para transferir grandes cantidades de datos.

> Actualmente es una tecnología prácticamente obsoleta frente a las conexiones de banda ancha modernas.

---

## 🏢 Conexiones a Internet empresariales

Las empresas pueden necesitar conexiones con **mayor disponibilidad, capacidad y confiabilidad** que las conexiones domésticas.

Entre las opciones se encuentran:

### 🔗 Líneas arrendadas dedicadas

Son **circuitos reservados dentro de la red del proveedor** que permiten conectar oficinas ubicadas en diferentes lugares.

Pueden utilizarse para transportar **voz y datos** mediante una conexión privada.

```text
Oficina A ─── Línea dedicada ─── Oficina B
```

---

### 🌐 Metro Ethernet

**Metro Ethernet** extiende la tecnología **Ethernet**, utilizada normalmente en redes LAN, para proporcionar conectividad a través de una **WAN**.

```text
LAN ─── Ethernet ─── Red del proveedor ─── Ethernet ─── LAN
```

---

## 🔄 Redes convergentes

Tradicionalmente podían existir **redes separadas** para diferentes servicios:

```text
Datos ─── Red de datos
Voz   ─── Red telefónica
Video ─── Red de video
```

Una **red convergente** permite transportar diferentes tipos de comunicación utilizando **una misma infraestructura de red**.

```text
        ┌── Datos
        │
Red ────┼── Voz
        │
        └── Video
```
