## 🌐 Natas Level 0

En este primer nivel de Natas comencé a practicar la inspección de una aplicación web desde el lado del cliente.

La página indicaba que la contraseña para acceder al siguiente nivel se encontraba en la propia página, aunque no era visible directamente.

### 🔎 Resolución

Utilicé las **DevTools** del navegador para inspeccionar el código HTML recibido.

Dentro del HTML encontré un comentario que contenía la contraseña para el siguiente nivel.

<img width="1405" height="697" alt="image" src="https://github.com/user-attachments/assets/8b2f5642-709e-4def-87f4-742dd492136f" />


### 🧠 ¿Qué aprendí?

- A utilizar **DevTools** para inspeccionar el HTML de una página.
- Que el contenido que no aparece visualmente puede seguir estando presente en el código recibido por el navegador.
