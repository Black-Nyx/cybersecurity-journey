# Natas 1 → Natas 2

## Objetivo

En este nivel, la página indicaba que la contraseña para acceder al siguiente nivel se encontraba en la propia página, pero que el **clic derecho estaba bloqueado**.

---

## Resolución

Aunque el clic derecho estaba deshabilitado, esto no impide acceder a las herramientas de desarrollo del navegador.

Abrí las **DevTools** utilizando:

```text
F12
```

Luego inspeccioné el código HTML de la página y encontré allí la contraseña necesaria para avanzar al siguiente nivel.
